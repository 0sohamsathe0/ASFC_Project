# 🏆 Fencing Club Management System

A full-stack MERN web application designed to manage fencing club activities including player registration, admin approvals, and tournament management.

This system provides a secure authentication system, document verification, and an admin dashboard to efficiently manage club members and events.

## Current branch: `UI-Changes`

This branch covers UI updates across the public website and admin interface, including homepage presentation, navigation, responsive admin layouts, player management, tournaments, results, and Attendance integration. Its scope has expanded beyond the original fees-management focus.

See [AGENTS.md](AGENTS.md) for project conventions and [the responsive admin architecture plan](ADMIN_RESPONSIVE_ARCHITECTURE_PLAN.md) for the original admin refactor plan.
